# Tài liệu tham khảo ngôn ngữ lập trình Java 25

Bộ tài liệu này được thiết kế như một dạng tài liệu tham khảo, giúp các bạn nắm được tất cả những khái niệm và thành phần của Java (mục tiêu **JDK 25 LTS**). Vì ở dạng tham khảo nên sẽ có một số khó khăn và không phù hợp với người học từ đầu, nếu chưa biết gì về Java, bạn nên tìm một giáo trình đơn giản hơn (xem bên dưới) và dùng tài liệu này để tham khảo kỹ hơn trong quá trình học.

---

Tham khảo nếu bạn chưa biết về Java: [The Java Tutorials](https://docs.oracle.com/javase/tutorial/) · [OpenJDK 25](https://openjdk.org/projects/jdk/25/)
